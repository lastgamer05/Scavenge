# Scavenge

Top-down one-hit-kill extraction looter made with Godot 4.7. See [docs/GDD.md](docs/GDD.md) for the design.

- Play: https://lastgamer05.github.io/Scavenge/
- Project: `game/` (open `game/project.godot` in Godot 4.7.2)
- Tests: `godot --headless --path game --script res://tests/run_tests.gd` and `res://tests/sim_test.gd`
- Map generator: `python tools/gen_test_yard.py`

Font: Galmuri11 (SIL Open Font License), see `game/assets/fonts/Galmuri-LICENSE.txt`.
