# Scavenge — 게임 기획서

## 한 줄 소개

탑다운 원샷킬 액션에 그리드 가방 정리를 붙인 익스트랙션 루터. 폐허에서 최대한 많이 쓸어 담고, 살아서 빠져나와라. 가방이 찰수록 욕심은 커지고, 정리하는 몇 초가 죽음이 될 수 있다.

엔진: Godot 4.7 (GL Compatibility), 웹 빌드로 GitHub Pages 배포.

---

## 1. 코어 루프

```
은신처(바파스 거점) → 출격(맵 선택, 장비 반입) → 약탈(전투 + 루팅 + 가방 정리)
→ 탈출(익스트랙션 포인트) → 은신처(판매 / 기부 / 퀘스트 / 스토리) → 반복
```

- 한 판 10~18분.
- 사망 시 들고 간 모든 것을 잃는다. 안전 파우치에 넣은 것만 남는다.

---

## 2. 전투

순수 아케이드 템포를 유지한다. 무거운 결정은 전부 가방 쪽으로 몰아넣는다.

- 원샷 원킬이 기본. 방어구가 있으면 1~2발 더 버틴다.
- 재장전 없음. 총은 탄이 든 채로 줍고, 다 쓰면 던진다. 던진 무기에 맞은 적은 기절한다.
- 적이 떨어뜨린 무기를 바로 주워 교체한다. 무기 순환이 곧 탄약 관리다.
- 맨손 공격과 던지기는 적을 기절시킨다. 기절한 적은 처형할 수 있다.
- 무기 개성은 연사력, 탄 퍼짐, 소음 크기, 관통 여부로 준다. 반동과 조준 페널티는 없다.
- 소음 시스템: 총성은 주변 적을 끌어모은다. 소음기와 근접 무기의 가치가 여기서 나온다.
- 퀵슬롯: 허리에 무기 2개, 벨트에 소모품 3개. 모두 가방을 열지 않고 즉시 쓴다.

## 3. 가방

### 그리드 인벤토리
- 아이템마다 모양이 있다(권총 2x1, 소총 4x1, 금괴 1x1, 식량 상자 2x2).
- 회전, 배치, 겹침 금지.
- 가방 종류: 허리 파우치 2x2 → 배낭 4x4 → 군용 백팩 6x5 → 특수 모양 가방.

### 실시간 정리
- 가방을 여는 동안 게임은 멈추지 않고 30% 속도로 느려진다.
- 시체나 상자를 뒤지면 내 가방과 상대 가방이 나란히 뜬다.
- Shift+클릭으로 빈자리에 자동으로 넣는다.
- 자동 정렬은 판 안에서 2초 무방비, 은신처에서는 무료.
- 가방이 꽉 찬 상태에서 주우면 "무엇을 버릴지" 한 줄 팝업만 뜬다.

### 판 안의 규칙은 용기 규칙 하나뿐
판 안에서는 "어디에 넣을지"만 고민하게 하고 "무엇 옆에 둘지"는 계산시키지 않는다.

- 깨지는 물건은 보호 케이스 밖에 있으면 피격 시 파손될 수 있다.
- 폭발물은 방폭 케이스 밖에 있으면 피격 시 터질 수 있다.
- 의약품은 냉장 케이스 안에 있어야 가치가 유지된다.
- 케이스 자체가 칸을 차지하므로 공간과 리스크 사이의 선택이 남는다.

### 은신처에서의 최적화
- 출격 전 가방 세팅, 창고 정리, 제작 재료 분류.
- 인접 시너지는 은신처 창고에만 둔다(예: 정비 키트 옆 무기는 판 사이에 수리됨).

### 무게
- 이동속도, 구르기 거리, 발소리 크기에 영향. 조준에는 영향 없음.

## 4. 맵

### 구조: 열린 필드 + 밀집 거점
- 실외: 이동과 선택의 구간. 순찰조 위주, 중저가 전리품, 엄폐물 촘촘히.
- 실내: 핫라인식 교전 구간. 방 밀집, 적 밀집, 고가 전리품.
- 맵 하나에 대형 건물 3~5개와 실외 거점 여러 곳. 한 판에 다 털 수 없다.

### 표현
- 건물에 들어가면 지붕이 투명해지고 카메라가 살짝 줌인된다.
- 층 이동은 계단 전환. 현재 층만 보이고 위아래 층은 소리 표시로만 안다.
- 실외 시야는 화면 범위로 제한. 저격총은 희귀하고 시끄럽다.
- 밤/안개 같은 시간대와 날씨 변수.

### 탈출 포인트

| 탈출 | 위치 | 조건 / 리스크 |
|---|---|---|
| 정문 검문소 | 맵 가장자리 | 상시 개방, 멀고 경비 있음 |
| 하수도 | 맨홀 | 대형 백팩 불가 |
| 보트 | 강변 | 시간 제한, 엔진 소리로 적 유인 |
| 옥상 헬기 | 고층 건물 꼭대기 | 호출 후 90초 농성 |
| 차량 | 실외 주차장 | 연료통(2x2) 필요 |

- 시간이 지나면 실외 순찰이 늘고, 마지막 몇 분엔 일부 탈출구가 닫힌다.
- 건물 배치는 고정, 내부 방 구성과 전리품은 랜덤.

## 5. 세계관

### 붕괴
10여 년 전 내전 막바지, 정체불명의 사건으로 도시 대부분이 하룻밤 사이에 버려졌다. 피난민은 아무것도 챙기지 못했다. 그래서 폐허에는 은행 금고, 연구소 장비, 군 보급창이 그대로 남아 있다.

### 센트라
붕괴 이후 성벽 도시를 세운 독재 정부. 배급을 충성도에 따라 나누고, 폐허에서 나오는 물자를 독점한다. 허가 없이 성벽 밖으로 나가는 것은 중죄다. 붕괴의 원인에 센트라가 관련되어 있고, 증거는 폐허 깊은 곳에 남아 있다.

### 세력

| 세력 | 성격 | 게임 속 역할 |
|---|---|---|
| 센트라군 | 정규군, 장비가 좋고 조직적 | 고난도 적, 보스, 핵심 지역 경비 |
| 사설 군사기업 | 센트라 하청 수거 부대 | 중급 적, 경쟁 약탈자 |
| 약탈자 무리 | 성벽에서 쫓겨난 생존자 | 하급 적, 수가 많고 소음에 몰려옴 |
| 바파스 | 센트라에 맞서는 레지스탕스 | 은신처 거점, 판 안에서는 가끔 아군 NPC나 구출 대상 |

## 6. 주인공: 토아

센트라 하청 사설 군사기업의 용병. 돈만 보고 움직이는 베테랑이고, 10년 전 이전의 기억이 흐릿하다. 본인은 내전 때 다친 탓이라고 알고 있다.

### 프롤로그 (플레이 가능한 튜토리얼)
1. 팀원 4명과 함께 붕괴의 진원지 시설에 들어가 봉인된 케이스를 회수한다.
2. 처음 와보는 곳인데 토아만 길을 안다. 문 비밀번호가 떠오른다.
3. 옥상 헬기로 탈출하려는 순간, 헬기 대신 폭격이 쏟아진다.
4. 눈을 뜨면 팀은 전멸했고 케이스는 부서졌다. 안에 있던 데이터 코어만 토아의 안전 파우치 안에 남아 있다.

### 사망 처리된 남자
- 회사는 팀 전원을 작전 중 사망으로 보고한다. 기록상 토아는 죽은 사람이다.
- 바파스가 폐허에서 쓰러진 토아를 발견한다. 그들은 데이터 코어에 관심을 보인다.
- 이해관계가 맞는다. 토아는 자신을 버린 자들에게 복수하고 싶고, 바파스는 코어의 내용이 필요하다. 정식 단원이 아닌 협력 관계다.
- 코어는 암호화되어 있다. 해독에는 장비, 부품, 돈이 필요하다. 이것이 루팅을 하는 이유다.

### 기억 조각
- 폭격 이후 특정 장소에 가면 기억이 떠오른다.
- 판 안에서 줍는 녹음기와 쪽지, 맵 특정 지점의 짧은 회상으로 과거가 풀린다.
- 코어 해독이 진행될 때마다 기억도 하나씩 맞춰진다.

### 진실 (2막 반전)
- 10년 전 붕괴 당일, 토아는 그 시설의 경비병이었고 유일한 생존자였다.
- 센트라는 토아의 기억을 지우고 사망 처리한 뒤 신분을 바꿔 용병으로 풀어놓았다. 시설 출입 권한이 생체 정보로 등록된 사람이 토아뿐이었기 때문이다.
- 이번 회수 작전 배정은 우연이 아니었다. 문을 열 열쇠로 쓴 뒤 폐기하려던 것이다.
- 토아는 두 번 죽은 사람이다. 10년 전에는 서류상으로, 이번에는 폭격으로.

### 핵심 인물
- 바파스 리더: 토아를 거뒀지만 끝까지 완전히 믿지는 않는다.
- 옛 팀장: 폭격에서 함께 살아남았지만 입막음 대가로 센트라에 붙었다. 반복 등장 보스.
- 센트라 측 책임자: 10년 전 사고와 이번 폭격을 모두 지시한 인물. 최종 목표.

## 7. 3막 구조

1. 생존과 협력: 바파스의 잡일로 신뢰를 얻고 코어 1차 해독. 옛 팀장의 생존을 알게 된다.
2. 두 번 죽은 남자: 기억과 코어가 맞춰지며 붕괴 당일의 진실과 토아의 정체가 드러난다. 옛 팀장과 결판.
3. 봉기: 코어 속 증거를 성벽 도시에 퍼뜨리고 공격한다. 마지막은 프롤로그와 같은 진원지 시설.

엔딩 분기: 코어를 바파스에 넘길지, 센트라와 거래해 목숨만 챙길지.

### 스토리를 루프에 녹이는 장치
- 메인 퀘스트는 특수 목표가 붙은 출격(문서 회수, 포로 구출, 보급 차량 습격).
- 스토리 아이템도 가방 칸을 차지한다. 기밀 문서를 챙기려면 금괴를 버려야 할 수 있다.
- 수배도: 스토리가 진행될수록 센트라군이 더 자주, 더 강하게 등장한다.

## 8. 은신처: 바파스 거점

전투 없이 같은 탑다운 시점으로 걸어 다니는 거점 마을.

| NPC | 역할 |
|---|---|
| 리더 | 메인 퀘스트, 스토리 진행 |
| 무기상 | 무기 구매와 개조 |
| 의사 | 회복, 의약품 거래, 냉장 케이스 의뢰 |
| 고물상 | 잡동사니 매입, 제작 재료 |
| 정보원 | 맵 정보, 이벤트 정보 |

- 물자를 바파스에 기부하면 세력 레벨이 오르고 새 NPC와 시설이 생긴다.
- 팔아서 내 장비를 살지, 기부해서 거점을 키울지가 메타 선택이다.

## 9. 아트 방향

스팀펑크 폐허, 32비트 픽셀아트. 컨셉아트와 프롬프트는 [art/](art/prompts.md)에 있다.

- **기본 톤 (R1 달빛)**: 차가운 청회색 달빛이 화면 전체의 기본 조명. 몇 개 남은 가스 가로등만 호박색으로 깜빡인다. 포근함 없이 황량하고 위험한 느낌.
- **적 거점 표시 (R3 불빛)**: 약탈자 모닥불, 불타는 드럼통, 손전등. 따뜻한 불빛이 보이면 "적이 있고 전리품도 있는 곳"이라는 신호.
- **건물**: 지붕이 무너지거나 걷힌 상태로 위에서 내부가 보인다. 벽은 금 가고 일부 무너졌지만 실내 교전이 가능할 만큼 방 구조는 온전하다. 엎어진 가구, 부서진 금고, 피 얼룩, 잔해.
- **가독성 원칙**: 바닥과 벽의 명암 대비를 항상 유지한다. 캐릭터, 무기, 전리품은 배경보다 밝게.
- **시간대 변주 (R2 황혼)**: 낮/황혼 맵이나 특정 지역용. 녹슨 주황과 긴 그림자.
- **구현 방향**: Godot 2D 조명. CanvasModulate로 달빛 톤을 깔고, PointLight2D로 가로등(깜빡임)과 모닥불(일렁임)을 올린다.

## 10. 개발 단계

| 단계 | 내용 |
|---|---|
| Phase 1 | 전투 코어: 이동, 사격, 원샷킬, 무기 줍기/던지기, 기절과 처형, 적 AI, 소음, 간단한 탈출 |
| Phase 2 | 가방: 그리드 인벤토리, 루팅, 슬로모션, 무게, 케이스 규칙 |
| Phase 3 | 오픈맵: 실외 필드, 건물 지붕과 층, 탈출 포인트 다양화 |
| Phase 4 | 은신처: 바파스 거점, NPC, 판매와 기부, 퀘스트 |
| Phase 5 | 스토리: 프롤로그, 기억 조각, 메인 퀘스트 |
